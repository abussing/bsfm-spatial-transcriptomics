# Provenance, not workflow

Use the [workflow guide](../WORKFLOW_GUIDE.md) for current methods and commands.
Scientific choices are recorded in `docs/decisions/`; implementation source maps
and focused tests identify the selected code and its validation scope.

The ledgers here record candidates as well as selected sources. Inclusion is not
acceptance. Preserve distinctions such as selected, historical, rejected and
unresolved; do not choose an implementation by filename or recency.

Raw search captures, directory listings and superseded mesh-study files are
preserved in the [fixed historical evidence tree](https://github.com/abussing/bsfm-spatial-transcriptomics/tree/7b9925b8514cb1c9bcf6b516c30273c6e8b71024/docs/recovery/evidence).
Old relative paths in capture ledgers refer to that tree. They can also be read
offline from a full clone with `git show 7b9925b8514cb1c9bcf6b516c30273c6e8b71024:PATH`.
The few captures still under `evidence/` support existing frozen input contracts;
the gene-panel reference table supports an executable selection regression.
They are evidence fixtures, not new-analysis recipes. New analysis inventories,
plots, job specifications and logs belong outside this repository.
